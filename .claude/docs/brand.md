# Бренд-система «Мисливська лавка»

> Стисло з `source/online_viewer_net.html` (брендбук). Джерело design tokens для Tailwind / shadcn/ui.

## Позиціювання
Спеціалізований магазин товарів для полювання, риболовлі та активного відпочинку. 50 000+ товарів, 500+ брендів.
Цінності: **Професійний · Практичний · Компетентний**. Гасло: «Спорядження, якому довіряють.»

Hero-градієнт: `linear-gradient(135deg, #233d49, #3d677b 48%, #18282e)` + радіальний bronze-відблиск.

## Типографіка
- **Merriweather** 400/700 (serif): заголовки, бренд, ціни на цінниках, цитати.
- **Inter** 400/500/600/700 (sans): UI, ціни, характеристики, кнопки, навігація.
- Eyebrow: 12px, 700, uppercase, letter-spacing .16em, колір bronze.
- Кнопки: Inter 600 13px, uppercase, letter-spacing .05em.

## Форма
- `border-radius: 4px` (мінімальні заокруглення, строгий стиль).
- Контейнер: max 1240px, gutter 24px.
- Секції: великий вертикальний ритм (110px desktop / 75px mobile).
- Картки: білий фон, 1px бордер, без важких тіней.

## Tone of voice
Професійно. Коротко. По суті. «Менше маркетингових фраз — більше корисної інформації.»
- Без рекламних перебільшень.
- Характеристики, сумісність, сценарії використання.
- Ключові факти в тексті, не лише на зображеннях (важливо також для SEO/GEO).
